### 1- Client ID and Client secret

> Crowdstrike API client secrets for the user account used to fetch assets by Cyclops (The user account must have the required permissions).

How to generate Client ID and Client Secret :

1. Sign in to CrowdStrike.
2. Go to Support &gt; API Clients and Keys. Click Add a new API client.
3. Provide the following details for the API client:
   - Client name: API client name, such as CyclopsIntegration.
   - API scopes: Select the **Read** for the scopes in [Required permissions](#required-permissions) below

![](https://holocron.so/uploads/9744bb75-2-\(5\).png)

1. Click Add and use the generated Client ID and Client secret

#### Required permissions

All the following must be set to **Read** in Falcon Admin Panel in order for the connector to work.

| Scope name in Crowdstrike | To fetch data for entity | Necessary Product license in Crowdstrike                                                               |
| ------------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------ |
| User Management           | Users                    | Falcon Insight XDR or Falcon Prevent or Falcon Intelligence or Falcon Intelligence Premium or Malquery |
| Assets                    | Devices                  | Falcon Discover or Falcon Exposure Management                                                          |
| Hosts                     | Devices                  | Falcon Insight XDR or Falcon Prevent                                                                   |
| Incidents                 | Incidents                | Falcon Insight XDR                                                                                     |
| Detections                | Findings                 | Falcon Insight XDR                                                                                     |
| Firewall management       | Policy                   | Falcon Firewall Management with either Falcon Insight XDR or Falcon Prevent                            |
| Response policies         | Policy                   | Falcon Insight XDR                                                                                     |
| Device control policies   | Policy                   | Falcon Device Control with either Falcon Prevent or Falcon Insight XDR                                 |
| Host Groups               | Policy                   | Falcon Device Control with either Falcon Prevent or Falcon Insight XDR                                 |
| Prevention policies       | Policy                   | Falcon Insight XDR or Falcon Prevent                                                                   |
| Falcon Container Image    | Kubernetes Clusters      | Falcon Cloud Workload Protection                                                                       |

### 2- CrowdStrike base URL

> The full URL of the API server – this could be one of the following:
> Default value: https://api.crowdstrike.com

1. https://api.crowdstrike.com (for v2 API - US region)
2. https://api.us-2.crowdstrike.com (for v2 API - US region)
3. https://api.eu-1.crowdstrike.com/ (for v2 API - EU region)
